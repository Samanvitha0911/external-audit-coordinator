# 🧠 AI Talking Points Card (Day 19)

---

## 🤖 Groq
Groq is an AI inference platform that runs large language models very fast.  
In this project, it is used to generate responses for categorization, queries, and report generation.

---

## 🔎 RAG (Retrieval-Augmented Generation)
RAG is a method where AI retrieves relevant data first and then generates an answer using that data.  
In this system, it improves accuracy by combining vector search results with LLM responses.

---

## 🗄️ ChromaDB
ChromaDB is a vector database used to store and search embeddings of text data.  
It helps find relevant audit information based on semantic similarity instead of keyword matching.

---

## 🧠 Prompt Engineering
Prompt engineering is the process of designing clear instructions for AI to get accurate and structured outputs.  
In this project, prompts are designed to ensure consistent JSON responses from the model.
