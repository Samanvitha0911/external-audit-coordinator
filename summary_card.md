# 🧠 AI-BASED EXTERNAL AUDIT COORDINATOR
### 📌 Project Summary Card (Demo Day)

---

## 👤 Project Overview
An AI-powered system that automates audit assistance tasks such as categorization, query answering, and report generation using LLMs and vector search.

---

## ⚙️ Tech Stack

- 🐍 Python (Flask)
- 🤖 Groq LLM (Llama 3.1)
- 🧠 ChromaDB (Vector Database)
- 🔴 Redis (Caching Layer)
- 🐳 Docker (Containerization)
- 🌐 REST APIs
- 📝 Postman / PowerShell (Testing)

---

## 🔌 API Endpoints (6 Core APIs)

1. `GET /` → Home Service Check  
2. `GET /health` → System Health Status  
3. `POST /categorise` → AI-based text classification  
4. `POST /query` → Context-based Q&A system  
5. `POST /generate-report` → Audit report generation  
6. `GET/POST /job-status/<id>` → Async job tracking  

---

## 🧠 Key Features

- AI-powered classification and reasoning
- Retrieval-Augmented Generation (RAG)
- Redis caching for performance optimization
- Fallback handling for API failures
- Dockerized deployment for portability
- Real-time API responses
